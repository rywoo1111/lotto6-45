# LOTTO 6/45 AI 최적화 엔지니어링 시스템 (v2.2)

본 프로젝트는 과거 역대 로또 당첨 이력을 데이터베이스(SQLite)화하고, NumPy 기반의 C-레벨 벡터 연산을 통해 **8,145,060개의 전체 조합**을 약 1~3초 내외로 필터링 및 채점하는 고성능 로또 예측/분석 파이프라인입니다.

## 🚀 주요 기능 및 특징 (v2.2 업데이트)

### 1. 하이퍼 스피드 필터링 엔진 (Hard Filter)
- **13대 정적 필터 & 6대 동적 패턴 제어**: 연속 번호, 끝수 플룸 차단, AC값(산술 복잡도), 과거 1등 당첨 이력 일치 검증, 이월수 딜레마 등 확률적으로 극히 희박한 조합(Overfitting)을 **1단계에서 사전 제거**합니다.
- `np.bincount`, `np.isin`, `np.bitwise_and` 등 순수 NumPy 벡터화 연산을 통해 for 루프 없이 814만 개 대용량 조합을 즉시 처리합니다.

### 2. 가중치 다각화 채점 엔진 (Soft Scoring & Pure Shuffle)
- 최근 10회차 통계 정보 추출을 통해 장기 미출현수(Cold) 및 중앙값 이하 비과열 구역(Cold Zone) 점수 가중치를 동적 산출.
- [v2.2] 상호 배타적 3단계 계층적 큐 가동: **0순위(마스킹 원천차단) -> 1순위(지정 고정수) -> 2순위(우량 풀 통합 Pure Shuffle)**로 파티셔닝.
- [v2.2] 기존 'Zone별 예산 강제 N할당' 로직을 폐기하고, **70점 컷오프를 통과한 전체 순수 우량 조합 대상 완전 무작위 셔플링(Pure Shuffle) 및 확률론적 비복원 추출**로 변경하여, 투자 예산(게임 수)의 자본 낭비 0% 달성.
- 동점자 처리 시 Random Noise (미세 난수) 기반 무작위 섞어내기 기법을 차용.

### 3. CLI 오케스트레이션 및 상태 관리 (Entry Point)
- CLI(명령줄 인터페이스)를 통해 예산(구입 게임 수) 및 다중 수동 제어(고정수, 제외수, 우대 존, 배제 존) 설정.
- 분석 메뉴([2번]) 제공: 최근 5~10회차의 동반 쌍, 이월 트렌드, 단기 초과열 번호, 누적 초과열 Zone 통계를 실시간으로 진단하고 6개 동적 하드필터를 ON/OFF 토글 가능.
- [대용량 안전 모드] 1억원(100,000만 게임) 등 극대화 데이터 처리 시, 100게임 이하 전량 콘솔 출력 / 100게임 초과 시 요약 출력 모드로 CMD I/O 버퍼 오버플로 방지.
- [UI 시인성 보강] 로또 마킹과 직관적으로 일치하도록 콘솔 교차 행(A, C, E...)과 짝수 행(B, D, F...)을 구분하는 노란색(ANSI `\033[93m`) 지브라 하이라이트 제공.

### 4. 사후 감사(Audit) 및 신뢰성 검증 시스템
- `WEEKLY_AUDIT_LOG` 테이블에 예측 이력을 영구 보존하며, 추첨 완료 시 실제 1등 조합과 교차 검증 (Recall & Precision 2중 측정).
- 투자금 대비 당첨금/순손익/수익률(ROI) 통계 자동 산출 및 대용량 통합 리포트(`predictions/audit_result.txt` / `.csv`) 지원.
- [v2.2] 오프라인 분기별 CSV 마이그레이션 외에도 **온라인 동행복권 실시간 벌크 크롤러(REST API 역공학)**를 신설 탑재.

## 🕹 CLI 메인 메뉴 구성 (1 ~ 14 기능 지원)

- **1 (동기화)**: 동행복권 온라인 크롤링 및 로컬 CSV 읽어오기 병행 지원.
- **2 (패턴 진단)**: 최근 트렌드 통계 기반 6대 동적 하드필터 제어 (ON/OFF 토글).
- **3 (추천 파이프라인)**: 세팅된 예산 및 수동 조건에 맞춰 파이프라인 가동. 기존 조합 존재 여부에 따라 Append(누적) 또는 신규 분기.
- **4 (사후 감사)**: 검증 대상 회차 당첨 정보로 Recall(하드필터 탈락 여부) 및 수익률(ROI) 종합 적중 리포트 생성.
- **5 (예산)**: 예산(기본 10,000원 -> 10게임)을 1,000원 단위 정수로 설정. (10억+ 대용량 할당 가능)
- **6 (제외)**: 특정 Zone 81만 개 조합에 대해 음수 페널티(-100점) 부여.
- **7 (가점)**: 특정 Zone 조합에 강제 +20점 영구 주입.
- **8 (고정수 A/B)**: 수동 할당 (A 강제 70점컷 제한 vs B 미달 시 강제 무시 추출).
- **9 (고정수 B)**: 실용주의 모드 수동 할당 매핑.
- **10 (제외수 A)**: 수동 배제 (원천 차단).
- **11 (제외수 B)**: 수동 배제 (원칙주의/실용주의 fallback 트리거 제어).
- **12 (초기화)**: 세션에 설정된 모든 수동 개입 초기화.
- **13 (조회)**: 과거 회차 추천 내역 복구/조회.
- **14 (종료)**: 시스템 자원 명시적 반환 및 클로즈.

## 🧱 데이터 모델 (SQLite Database)
- `LOTTO_COMBINATIONS_POOL`: 8,145,060개 마스터 풀 테이블. (`idx_zone`, `idx_nums` 인덱싱 구조화)
- `WINNING_HISTORY`: 역대 추첨 회차 1등 정보 누적 테이블.
- `WEEKLY_AUDIT_LOG`: 가동 시 생성된 예측/추천 로그 백업 및 자동 스코어링 추적 테이블.

## 🚀 Usage

시스템 초기 가동 혹은 마스터 DB 재구축 시:
```bash
python init_db.py
```

주간 정기 작동 메인 파이프라인:
```bash
python main.py
```
*(예측 구동 직후 `predictions/` 폴더 내에 누적된 TXT 및 CSV 통합 리포트 파일이 즉시 릴리즈됩니다.)*
